19. **Two limits of the idea itself (D-159).** A change made and undone between two scans is not seen. Executable memory that is not RWX (an attacker maps writable, writes, flips to execute) is not flagged by the RWX rule; a strict mode reporting every private executable region that is neither in a loaded image nor attested would close it, with false positives from drivers and overlays. Proposed, not built; the owner's call.
